Histsearch

A source-discovery workspace for historical epidemiology questions.

Histsearch is the research layer I use to turn half-formed historical disease questions into auditable source trails: search strings, result records, credibility notes, manual leads, and exportable dossiers. This page is the public interface shell; live searching runs through the local Python backend.

How to run it

From the local Histsearch project, start the backend before using this page:

histsearch serve --host 127.0.0.1 --port 8765

GitHub Pages can host the interface, but it cannot run the Python connectors or store private outputs. When the backend is running locally, the page can send a query to that local service and render the returned records.
